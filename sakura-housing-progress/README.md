# さくらハウジング 9月進捗報告（改訂版）

`さくらハウジング_進捗報告_改訂版.pptx`（16:9、5枚）を生成するスクリプト。

```bash
npm install
node build.js
```

## 書き換える場所（`build.js` の先頭「設定値」）

| 設定 | 内容 | 現在 |
|---|---|---|
| `OWNERS` | 施策01〜04の担当者 | 空（＝スライドに「要記入」と表示） |
| `PORTAL_MONTHLY_TARGET` | ポータル掲載の月目標（件数・反響数） | 空（＝「要記入」） |
| `FISCAL_YEAR_START_MONTH` | 年度の開始月 | 1（1〜12月と仮定） |
| 売上の元データ | 目標・累計・仲介込み累計・当初月目標 | 元資料の値 |

達成率・計画ペース・差・必要月額などは、すべてこの設定値から計算して表示する。

## 未確定事項

- 年度の区切り（1〜12月と仮定）
- 各施策の担当者
- ポータル掲載の月目標
- 期限は案（発表者が実態に合わせて修正）
