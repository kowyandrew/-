# さくらハウジング 9月進捗報告（改訂版）

`さくらハウジング_進捗報告_改訂版.pptx`（16:9、5枚）を生成するスクリプト。

```bash
npm install
node build.js
```

## 書き換える場所（`build.js` の先頭「設定値」）

| 設定 | 内容 |
|---|---|
| `ACTUALS` | 月別実績（円）。出典はスプレッドシート「さくらハウジング_実績数値管理シート」の55期タブ（65・69・51・26・28・52行） |
| `ANNUAL_TARGET` / `LAST_YEAR_ANNUAL` | 年間目標 2,500万円／昨年 2,400万円（昨年は聞き取り値） |
| `FY_START_MONTH` | 年度の開始月（3月＝55期は2026年3月〜2027年2月） |
| `PHOTOS` | `photos/` に置いた写真のファイル名。空なら「写真を入れる枠」を表示 |
| `OWNERS` | 担当者。空なら「要記入」 |
| `PART_SCHEDULE` | パートさんの勤務（週2日） |

月が進んだら `MONTHS` と `ACTUALS` に列を足すと、達成率・見込み・グラフがすべて計算し直される。
