# さくらハウジング 9月進捗報告（改訂版）

`さくらハウジング_進捗報告_改訂版.pptx`（16:9、5枚）を生成するスクリプト。

```bash
npm install
node build.js
```

## 書き換える場所（`build.js` の先頭「設定値」）

| 設定 | 内容 | 現在 |
|---|---|---|
| `OWNERS` | 施策01〜03の担当者 | 空（＝スライドに「要記入」と表示） |
| `MIX` | 積み上げ棒グラフ用の昨年・今年（1〜8月）の売上合計・AD・付帯商品 | 空（＝グラフの代わりに「要記入」の枠） |
| `FISCAL_YEAR_START_MONTH` | 年度の開始月 | 1（1〜12月と仮定） |
| 売上の元データ | 年間目標・8月末累計（仲介込み）・昨年の年間売上 | 2,500／1,675／2,400 |

達成率・計画ペース・差・必要月額などは、すべてこの設定値から計算して表示する。

## 未確定事項

- 年度の区切り（1〜12月と仮定）
- 各施策の担当者
- AD・付帯商品の金額（グラフ用）
- 「DFE」は会計の外注先の名前として記載
- 期限は案（発表者が実態に合わせて修正）
