# 類似プラン検索

過去の契約図（Google Drive 上のPDF）から属性を抜き出し、条件の近い過去案件を並べて見せる1枚ページ。
「過去にうちで契約した図面をもとに、うちの図面を作るAI」の第1段階。

## 何ができるか

- 敷地面積・延床面積（㎡／坪）・階数・居室数・LDKの帖数・市町村・仕様（太陽光、WIC、パントリーなど）を入れると、
  条件の近い順に過去案件が並ぶ。条件は入れた分だけ効く
- 各案件に平面図のサムネイル、面積表の数値（敷地・建築・延床・建蔽率・容積率）、部屋と帖数、オプション一覧が出る
- 「Driveで契約図を開く」で元のPDFに飛べる

## 仕組み

```
Google Drive の契約図PDF
   │  （案件ごとに代表1ファイルを選ぶ。案・配置図のみ・修正版は除く）
   ▼
extract.py  ── PyMuPDF で本文を読み、正規表現で属性を抜く ──▶ plans.json
   │             ・工事名称／建築地／契約日（令和表記を西暦に）
   │             ・トータル面積表（敷地・建築・1階・2階・延床・建蔽率・容積率）
   │             ・部屋名と「（9.11㎡ 5.5帖）」の並びから部屋一覧、居室数、nLDK
   │             ・最高高さ、前面道路、OP:の行（オプション）、特徴キーワード
   │  平面詳細図のページを JPEG にして thumbs/ に置く
   ▼
build.py ── plans.json → plans.js（ページが <script src> で読む）
   ▼
index.html （公開ページ。外部通信なし、全部クライアント側で並べ替え）
```

### PDFの2種類

| 種類 | 時期の目安 | 文字 | 抽出 |
|---|---|---|---|
| CADから出力したPDF（Microsoft Print to PDF 等） | 2024年後半〜 | 取れる | 自動で全項目 |
| 複合機でスキャンしたPDF（Apeos 等） | 〜2024年前半 | 取れない | DriveのOCR文字列と目視で補完。`manual.json` に手入力 |

スキャン品は面積や部屋が欠けていることがある。カードに「スキャン」の札が付く。

## 更新のしかた

1. Drive から新しい契約図PDFを `pdf/<fileId>.pdf` として置く（このセッションでは Drive MCP でダウンロードした）
2. `cases/*.json` に案件行を足す（`selected: true`、`fileId`、`customer`、`viewUrl`、`modifiedTime`）
3. 抽出とサムネイル生成

   ```sh
   pip install pymupdf
   python3 extract.py --cases cases/*.json --pdfdir pdf --out plans.json --thumbs thumbs --ocr ocr.json --manual manual.json
   python3 build.py plans.json plans.js
   ```

4. `index.html` を同じアーティファクトURLに再公開する（`plans.js` と `thumbs/` を一緒に）

## 注意

- 施主名・建築地が入るため、ページは社内限定で扱うこと（アーティファクトは初期状態で非公開）
- 抽出値は図面の面積表から機械的に読んだもの。確認申請の数値・最終の確定図とは違うことがある
- 「一致度」は条件との差をペナルティにした目安で、設計上の妥当性を保証するものではない
