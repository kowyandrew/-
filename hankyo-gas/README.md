# 反響メール自動取込（さくらハウジング）

Gmail のラベル「反響」に届く SUUMO・アットホームからの反響メールを、
5分ごとに読み取って反響台帳スプレッドシートに自動で行追加する Google Apps Script。
あわせて初回返信の文案を作り、**お客様のメールアドレス宛の Gmail 下書き**として用意する。
文面はシートには書かない。

**自動送信は一切しない。** 送信ボタンは必ず人が押す。

---

## 何が自動になるか

| これまで | これから |
|---|---|
| 反響メールを開いて、氏名・電話・物件名をシートに手入力 | 5分以内にシートへ自動で1行追加 |
| 返信文を毎回イチから書く | お客様宛の下書きが Gmail にできている。直して送るだけ |
| 転記漏れ・二重入力 | Gmailのメッセージ ID で照合するので取りこぼしも重複もない |

---

## 導入手順（30分程度）

### 1. Gmail 側の準備

反響メールに**ラベル「反響」が自動で付く**ようにする。すでに付いているなら飛ばしてよい。

Gmail → 設定 → フィルタとブロック中のアドレス → 新しいフィルタを作成

- From に `system@jds.suumo.jp OR mailtofax@athome.jp` （自社HPの送信元も OR で足す）
- 「ラベルを付ける」→ 反響

### 2. スクリプトを貼る

1. 反響台帳のスプレッドシートを開く
2. 拡張機能 → Apps Script
3. 左の「ファイル」＋ で、この `hankyo-gas/` の `.gs` ファイルを**同じ名前で6つ**作り、中身を貼る
   - `01_設定` `02_取込` `03_解析` `04_シート` `05_返信案` `06_テスト`
   - （`clasp` を使えるなら `clasp push` で一括でも同じ）

### 3. 自社の情報を入れる

`01_設定.gs` の **★** が付いた行を書き換える。

```js
自社電話: '0475-XX-XXXX',
自社住所: '千葉県東金市○○',
営業時間: '9:00〜18:00',
定休日: '水曜日',
担当者名: '関戸',
```

### 4. 解析を確かめる（シートには触らない）

`06_テスト.gs` の **`テスト_解析`** を実行 → [実行ログ] を見る。
実際に届いた3通で、氏名・電話・物件名・問合せ内容が正しく取れることを確認できる。

続いて **`テスト_返信案`** で文案を確認し、文面が気に入らなければ
`05_返信案.gs` の `テンプレートで作る_` を直接書き換える。

### 5. 空振りで本番を確かめる

**`試し取込`** を実行。Gmail から実際の反響を読み、
「何行目に何が入るか」だけをログに出す。シートは変更されない。

### 6. 動かす

**`初期セットアップ`** を1回実行する。
これで管理列が用意され、5分ごとの自動実行が始まる。

止めたいときは `トリガーを解除` を実行する。

## シートに書かれる内容

既存の列（`反響日` `反響時間` `反響経路` `名前` `フリガナ` `電話番号` `反響物件名`）に加えて、
`備考` の右側に管理用の列が自動で作られる。

| 列 | 中身 |
|---|---|
| メールアドレス | 返信先 |
| 問合せ内容 | 「この部屋の最新の空室状況を知りたい」など |
| 賃料 / 所在地 / 間取り | 物件の概要 |
| Gmailリンク | 元メールを開くURL |
| メッセージID | 重複取込の防止に使う。**消さないこと** |

`返信日` 以降の追客・ステータス列には何も書かない。これまで通り手で運用する。

---

## 手入力（飛込・紹介・リピート）との併用

**そのまま混ぜて使える。** Web 経由は自動、それ以外はこれまで通り手入力でよい。

- スクリプトが**既存の行を読むのは `メッセージID` 列だけ**。手入力行はここが空なので素通りする。
  書き換えも削除もしない
- 追記は必ず最終行の下。しかも**担当する列だけを差し替える**ので、
  その行に人が仕込んだ数式や入力規則の値は残る
- **行の並べ替えは自由**。重複判定は行の位置ではなく `メッセージID` の照合なので、
  反響日順に並べ直しても、途中に手入力行を挿入しても壊れない
- 自動で入った行は `メッセージID` 列が埋まっている。手入力行と見分けたいときはこの列で絞り込む
  （フィルタ表示や条件付き書式で色を付けてもよい）

唯一気をつける点は、**シートの一番下に集計行やメモ行を置かないこと**。
新しい反響はその下に追加されてしまう。集計は別シートに置く。

列は**見出し名で探している**ので、途中に列を挿しても壊れない。
ただし見出しの文字を変えると見失うので、変えたときは `01_設定.gs` の `管理列` と
`04_シート.gs` の `値` の対応表も直すこと。

## 反響経路が増えたとき

1. `テスト_生メールを見る` を実行し、その経路のメールの **From** と本文の形を確認する
2. `01_設定.gs` の `反響元一覧_()` に1行足す

```js
{ 名称: '○○', 差出人: /example\.co\.jp/i, 番号有無: true, 形式: '汎用' },
```

3. Gmail のフィルタにも、その差出人を `OR` で足してラベル「反響」が付くようにする

3. 項目が拾えないものがあれば、`01_設定.gs` の `ラベル別名` にそのメールでの書かれ方を足す

```js
名前: ['名前(漢字)', 'お名前', '氏名', 'お客様名', 'ご氏名', '名前', 'ご依頼者名'],
```

全角・半角、`ＴＥＬ`／`TEL`、`：`／`:`、桁揃えの全角スペースは
NFKC 正規化でまとめて吸収しているので、別名は**半角に直した形**で書く。

## 返信の下書きについて

反響1件につき、**お客様のメールアドレス宛の下書き**が Gmail の「下書き」に1通できる。
用件（空室確認／資料請求／内見／来店／費用）を判別して文面を変えている。

- **宛先はお客様**。SUUMO やアットホームではない
- **件名に「Re：」は付けない**。お客様から直接メールをもらったわけではないため
- **送信は絶対にしない。** 送信ボタンは人が押す
- **メールアドレスのない反響（電話のみ）は下書きを作らない。**
  シートに電話番号が入っているので、そちらを見て架電する
- 下書きの作成に失敗しても、シートの行は先に書かれているので反響は失われない

文面を変えたいときは `05_返信案.gs` の `テンプレートで作る_` の中の日本語を直接書き換える。
`テスト_返信案` を実行すると、宛先・件名・本文をまとめて確認できる。

## 返信文を AI で清書する（任意）

テンプレートのままでも実用になる。もう一段、反響の内容に合わせて
自然な文章にしたい場合のみ。

1. <https://console.anthropic.com/> で API キーを発行する
2. Apps Script の ⚙ プロジェクトの設定 → スクリプト プロパティ →
   `ANTHROPIC_API_KEY` という名前でキーを登録する
3. `01_設定.gs` の `AIで返信文を作る` を `true` にする

- 空室状況など**確認していない事実を断定しない**ように指示してある
- API が落ちても失敗しても、テンプレートの文面にそのまま戻る（業務は止まらない）
- 1通あたり数円程度。〔不確実：実際の従量課金は送信文字数で変わる〕

**お客様の氏名・電話番号が外部 API に送られる。** 気になる場合は `false` のままでよい。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 「シートが見つかりません」 | `設定.シートGID` が違う。エラーメッセージに候補の gid が出るので、それを入れる |
| 何も取り込まれない | Gmail にラベル「反響」が付いていない。`テスト_生メールを見る` で確認 |
| 一部の項目が空 | そのメール書式のラベル名が未登録。`ラベル別名` に足す |
| 電話番号が窓口の番号になる | そのメールのフッターの番号を `01_設定.gs` の `無視する電話番号` に足す |
| 反響でないお知らせメールが入る | 名前もメールアドレスも無ければ見送る。ログに理由が出る |
| 下書きができていない | 反響にメールアドレスが無い（電話のみ）。仕様なので電話で対応する |
| 同じ反響が2行入った | 行を消すつもりで `メッセージID` セルの中身だけ消した。`Gmailリンク` も見るようにしたが、掃除のときは**行ごと削除**すること |
| 日付が勝手に変換される | `設定.日付を文字列で書く` を `false` にすると本物の日付値で入る |

---

## 設計上、あえてやっていないこと

- **自動送信しない** — 誤送信の被害が大きく、取り消せない
- **追客・ステータス列を触らない** — 人の判断が入る欄で、機械が上書きすると事故になる
- **重複判定を「氏名＋電話」でやらない** — 同じ人が別物件で再問合せするのは正常な反響で、
  それを重複として弾くと商機を落とす。Gmail のメッセージ ID だけで判定する
