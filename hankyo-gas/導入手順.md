# 導入手順（GAS をはじめて触る人向け）

上から順にやれば動く。所要 30〜40分。
Google の画面表示は時々変わるので、ボタン名が少し違っても落ち着いて近いものを探すこと。

---

## 第0段階　どのアカウントでやるか決める（最重要）

**反響メールが届いているアカウント**で全部やる。ここを間違えると何も取り込めない。

Apps Script の `GmailApp` は「スクリプトを承認したアカウントの受信箱」しか読めない。
別アカウントで承認すると、そちらの空の受信箱を見にいって0件で終わる。

- 反響メールが届くアカウント（さくらハウジング側）を **A** とする
- 反響台帳のスプレッドシートを **A から開ける**ようにしておく
  - A が所有者でなくてよい。**編集者として共有**されていればよい
  - 共有されていなければ、今の所有者から A に編集権限を付けてもらう

ブラウザで複数の Google アカウントにログインしていると事故りやすい。
**シークレットウィンドウで A だけにログインして作業する**のが確実。

---

## 第1段階　Gmail に自動でラベル「反響」を付ける

すでにラベル「反響」が自動で付いているなら飛ばしてよい。

1. Gmail（アカウント A）を開く
2. 右上の ⚙ → **すべての設定を表示**
3. **フィルタとブロック中のアドレス** タブ → **新しいフィルタを作成**
4. **From** の欄に、反響メールの差出人を `OR` でつなげて入れる

```
system@jds.suumo.jp OR mailtofax@athome.jp
```

5. **フィルタを作成** を押す
6. **ラベルを付ける** にチェック → **新しいラベル** → `反響` を作成
7. 下の **○件の一致するスレッドにもフィルタを適用する** にもチェックを入れて **フィルタを作成**

過去の反響メールにもラベルが付く。

> 自社HP（チェシャ）の反響メールの差出人アドレスが分かったら、
> `OR` でここに足す。

---

## 第2段階　Apps Script を開く

1. 反響台帳のスプレッドシートを開く
2. 上のメニュー **拡張機能** → **Apps Script**
3. 別タブでエディタが開く。`コード.gs` という空のファイルが1つある

左端に縦のアイコンが並んでいる。使うのはこの4つ。

| アイコン | 名前 | 何に使うか |
|---|---|---|
| `<>` | エディタ | コードを書く。ふだんここ |
| 時計 | トリガー | 自動実行の設定を見る |
| ≡ | 実行数 | 自動実行が成功しているか確認する |
| ⚙ | プロジェクトの設定 | API キーを入れる（AI清書を使う場合のみ） |

右上の **無題のプロジェクト** を押して `反響取込` など分かる名前にしておく。

---

## 第3段階　コードを貼る

### 方法A：1つのファイルにまとめて貼る（手っ取り早い）

Apps Script は複数ファイルでも中身は全部つながって動くので、
最初からある `コード.gs` に**6つのファイルの中身を上から順に貼るだけ**でも動く。

1. `コード.gs` の中身（`function myFunction() {}` だけ書いてある）を全部消す
2. `01_設定.gs` → `02_取込.gs` → `03_解析.gs` → `04_シート.gs` → `05_返信案.gs` → `06_テスト.gs`
   の順に、それぞれの中身を続けて貼る
3. 💾 を押して保存

### 方法B：6ファイルに分ける（後で直しやすい。おすすめ）

左の **ファイル** の横の **＋** → **スクリプト** を押すと新しいファイルができる。
ファイル名を聞かれるので `01_設定` と入れる（`.gs` は自動で付く）。
これを6回くり返して、それぞれに中身を貼る。

| 作るファイル名 | 中身 |
|---|---|
| `01_設定` | `01_設定.gs` |
| `02_取込` | `02_取込.gs` |
| `03_解析` | `03_解析.gs` |
| `04_シート` | `04_シート.gs` |
| `05_返信案` | `05_返信案.gs` |
| `06_テスト` | `06_テスト.gs` |

最初からある `コード.gs` は、右の「⋮」→ **削除** で消してよい。

貼り終えたら 💾 で保存する。赤い波線やエラーが出ていなければOK。

---

## 第4段階　自社の情報を書く

`01_設定.gs`（方法Aなら上の方）の **★** が付いた行を書き換える。

```js
自社電話: '0475-XX-XXXX',       // ★ 実際の番号
自社住所: '千葉県東金市○○',      // ★ 実際の住所
営業時間: '9:00〜18:00',         // ★
定休日: '水曜日',                // ★
担当者名: '関戸',                // 返信メールの差出人名
```

`'` （シングルクォート）で囲んだ中だけを書き換える。
クォートやカンマを消すとエラーになる。

スプレッドシートIDとシートGIDはすでに入っている。別のシートに変えるときだけ触る。

💾 で保存。

---

## 第5段階　初回実行と承認（ここが山場）

1. エディタ上部の関数選択ドロップダウン（`myFunction` などと出ている所）で
   **`テスト_解析`** を選ぶ
2. **▶ 実行** を押す
3. **「承認が必要です」** というダイアログが出る → **権限を確認**
4. アカウント選択画面 → **アカウント A** を選ぶ

ここから先は、アカウントの種類で画面が分かれる。

### 会社の Google Workspace アカウントの場合

たいてい権限一覧がそのまま出る。**許可** を押せば終わり。

**「管理者によってブロックされています」と出たら**、
Workspace の管理者に「内部アプリの実行を許可してほしい」と依頼する必要がある。
自分が管理者なら、管理コンソール → アプリ → Google Workspace →
Google Cloud Platform → 「内部アプリを信頼する」あたりの設定。

### 個人の Gmail アカウントの場合

**「このアプリは Google で確認されていません」** という赤っぽい警告画面が出る。
これは**自分で書いたスクリプトだから出る**もので、異常ではない。

1. 左下の **詳細** をクリック
2. 下に出てくる **「反響取込（安全ではないページ）に移動」** をクリック
3. 権限の一覧が出る → **許可**

### 許可する権限の中身

| 権限 | 何に使うか |
|---|---|
| スプレッドシートの閲覧・編集 | 台帳に行を追加する |
| Gmail の閲覧・作成・送信・削除 | 反響メールを読み、ラベルを付け、下書きを作る |
| 外部サービスへの接続 | AI清書を使うときだけ。使わなければ一切通信しない |

> Gmail の権限に「送信」が含まれるのが気になると思う。正確に書いておく。
>
> **お客様宛にメールを送るコードは1行もない。** 全文を `send` で検索すると、
> ヒットするのは `02_取込.gs` の `MailApp.sendEmail` 1か所だけで、
> これは**取込が失敗したときに自分宛にエラーを知らせる**もの。
> `01_設定.gs` の `失敗通知先` を空（既定）にしておけば、それすら動かない。
>
> それでも権限表示から「送信」を消したい場合は、`02_取込.gs` の
> `MailApp.sendEmail(...)` の3行を削除し、`appsscript.json` から
> `script.send_mail` を外せばよい。エラーは実行ログには残り続ける。

## 第6段階　解析の確認（Gmail もシートも変更しない）

第5段階で `テスト_解析` が走っているはず。
画面下に **実行ログ** が開いて、こう出ていれば成功。

```
───── アットホーム（資料請求） ─────
反響経路 : アットホーム（番号あり）
名前     : 廣田結香
電話番号 : 070-9167-5511
物件名   : 南飯塚中古住宅
問合せ   : 資料を送って欲しい
```

これは**同梱した実メール3通**を解析したもので、Gmail は見ていない。

次に **`テスト_返信案`** を選んで実行し、**宛先・件名・本文**を確認する。

```
宛先: syuka971105@gmail.com
件名: 【御園建設株式会社 東金支店 さくらハウジング】南飯塚中古住宅 のお問い合わせありがとうございます
下書き: 作る（宛先 syuka971105@gmail.com）
```

文面を変えたければ `05_返信案.gs` の `テンプレートで作る_` の中の日本語を直接書き換える。
返信文はシートには書かれない。出力先は Gmail の下書きだけ。

---

## 第7段階　空振りで本番データを確認（シートは変更しない）

**`試し取込`** を選んで実行する。

今度は**実際の Gmail** を読む。ラベル「反響」の直近30日分から、
まだシートに入っていない反響を見つけて、**何が入るかだけ**をログに出す。
シートには1文字も書かない。

```
（試し取込）新規は 7件でした。シートは変更していません。
```

ここで件数が **0件** なら、

- Gmail にラベル「反響」が付いていない → 第1段階に戻る
- アカウントを間違えた → 第0段階に戻る

のどちらか。**`テスト_生メールを見る`** を実行すると、
ラベル「反響」の直近14日のメールの差出人と本文の頭が出るので、原因が分かる。

---

## 第8段階　本番開始

ログの中身に納得できたら、**`初期セットアップ`** を選んで実行する。

これで2つのことが起きる。

1. シートの `備考` の右に管理用の列が作られる
2. **5分ごとの自動実行**が設定される

実行ログに `セットアップ完了。` と出れば終わり。
5分待ってシートを見ると、反響が入っている。
Gmail の **下書き** を開くと、メールアドレスのある反響の分だけ返信の下書きができている。

---

## 第9段階　動いているかの確認

### ふだんの確認

左の **≡ 実行数** を開く。5分おきに `取込実行` が並んでいて、
ステータスが **完了** なら正常。

### 止めたいとき

関数選択で **`トリガーを解除`** を実行する。手入力だけの運用に戻る。
再開したいときは `初期セットアップ` をもう一度実行する。

### 失敗したとき

Apps Script は自動実行が失敗すると、アカウント A に通知メールを送る。
`01_設定.gs` の `失敗通知先` にアドレスを入れておくと、
そちらにもエラー内容が届く。

## 使用量について

5分間隔だと1日288回動く。1回あたり数秒なので、
Apps Script の1日あたりの実行時間の上限には十分収まる見込み。
反響が増えて重くなったら、`02_取込.gs` の `everyMinutes(5)` を
`everyMinutes(15)` などに変えて間隔を空ければよい。

正確な上限は Google の
[Apps Script の割り当て](https://developers.google.com/apps-script/guides/services/quotas) を参照。

## つまずいたときの逆引き

| 症状 | 原因 | 対処 |
|---|---|---|
| `ReferenceError: 設定 is not defined` | 設定ファイルを貼り忘れ | `01_設定` の中身が入っているか確認 |
| `シートが見つかりません` | シートGIDが違う | エラー文に候補の gid が出るので `01_設定.gs` に入れる |
| `試し取込` が0件 | ラベル or アカウント | 第7段階の説明を参照 |
| 一部の列だけ空 | そのメール書式のラベル名が未登録 | `01_設定.gs` の `ラベル別名` に足す |
| 電話番号が窓口の番号になる | メール末尾の会社案内の番号を拾った | そのメールのフッターの番号を `01_設定.gs` の `無視する電話番号` に足す |
| 反響でないお知らせが行になる | 反響メールと同じ差出人から届く通知 | 名前もメールも無ければ自動で見送る。ログに理由が出る |
| 同じ反響が2行入った | `メッセージID` 列を消した | 列を復活させる。以後は消さない |
| 反響日が勝手に変換される | シートの自動変換 | `設定.日付を文字列で書く` を `false` にする |
| 下書きができない | 反響にメールアドレスがない | 仕様。シートの電話番号を見て架電する |
| 承認画面が出ない/ブロック | Workspace の制限 | 第5段階の管理者設定を参照 |
